Red Wine Quality Prediction

Project Overview

This project uses Machine Learning to predict red wine quality based on its physicochemical properties.

Project Objectives

- Understand and explore the wine quality dataset.
- Perform data analysis and visualization.
- Train and compare Machine Learning regression models.
- Evaluate model performance using standard metrics.

Machine Learning Models

- Linear Regression
- Ridge Regression
- Decision Tree Regression
- Random Forest Regression

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

How to Run

1. Open the notebook in Google Colab.
2. Upload the dataset or configure its file path.
3. Run the notebook cells in order.
4. Compare the model evaluation results.

Project Files

- "Red_Wine_Quality_ML_Project.ipynb" — Machine Learning notebook
- "winequality-red.csv" — Dataset, if included
